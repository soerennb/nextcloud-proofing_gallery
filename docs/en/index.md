# Proofing Gallery documentation

Proofing Gallery publishes Nextcloud folders and copy-free collections as
branded client galleries. Originals remain regular Nextcloud files while the
app adds presentation, proofing, selection, upload, and delivery workflows.

- Start with the [user guide](user-guide.md) to create and deliver galleries.
- Use the [administrator guide](admin-guide.md) to install and operate the app.
- Read the [development guide](development.md) to work on the source code.

The user and administrator guides are also bundled into the app, so essential
documentation remains available when the Nextcloud server cannot reach GitHub.

For the current settings hierarchy, event release waves, privacy boundaries,
and operational queues, see the repository's architecture, operations, privacy,
and App Store publishing documents.
