# Proofing Gallery documentation

Branded delivery and collaborative photo proofing in Nextcloud.

## Choose a language

- [English documentation](en/index.md)
- [Deutsche Dokumentation](de/index.md)

The same user and administrator guides are included offline with every app
release. Developers can inspect and improve all documentation in the public
[GitHub repository](https://github.com/soerennb/nextcloud-proofing_gallery).

The English and German guides describe the current guided project, public-link,
proofing, download, and event-delivery workflows. Operational, privacy,
architecture, and release notes remain available in the repository.
